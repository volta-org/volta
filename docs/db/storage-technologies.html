Технологии хранения данных

Определение сущностей​

Сущности и атрибуты​

  • User - запись о пользователе в системе

    Атрибуты: UserID, Login, Rights, Name, Surname, Email

  • TestConfig - параметры запуска теста

    Атрибуты: ConfigID, RPS, Duration, URL, LoadType

  • TestStats - срез метрик, пишется раз в секунду

    Атрибуты: Timestamp, TestID, RPS, ErrorsPerSec, Latency, p50, p95, p99

  • Test - агрегат всех срезов

    Атрибуты: TestID, ConfigID, TotalRequests, TotalErrors, p50, p95, p99, Status

  • TestAnalysis - результат AI-анализа завершенного теста

    Атрибуты: ID, TestID, Status, Summary, Anomalies (список), Recommendations (список)
