- Name

- Email

### TestConfig:

- ConfigID
- RPS
- Duration
- URL
- Load type

- Timestamp

- Latency

- Error message

## Привязка к эндпоинтам

```
| Роут экрана          | Действие                       | Метод + Эндпоинт             | Модель (Request) | Модель (Response)  |
|----------------------|--------------------------------|------------------------------|------------------|--------------------|
| /tests/new           | Нажатие на кнопку "Start test" | POST /api/tests              | TestConfig       | TestID             |
| /tests               | При открытии экрана            | GET /api/tests               |                  | Array[TestPreview] |
| /tests               | Даблклик на поле               | GET /api/tests/{id}          |                  | Test               |
| /users               | При открытии экрана            | GET /api/users               |                  | Array[UserPreview] |
| /users               | Даблклик на поле               | GET /api/users/{id}          |                  | User               |
| /users/{id}          | Нажатие на кнопку "Save"       | PATCH /api/users/{id}        | UserUpdate       |                    |
| /users/new           | Нажатие на кнопку "Save"       | POST /api/users              | UserUpdate       | UserID             |
| /users/{id}          | Нажатие на кнопку "Delete"     | DELETE /api/users/{id}       |                  |                    |
| /tests/{id}/runtime  | При открытии экрана            | GET /api/tests/{id}          |                  | Test               |
| /tests/{id}/runtime  | Каждую секунду                 | GET /api/tests/{id}/stats    |                  | TestStats          |
| /tests/{id}/analysis | При открытии экрана            | GET /api/tests/{id}/analysis |                  | TestAnalysis       |
```

### TestPreview:

- TestID
- Load type
- URL
- Duration
- RPS

### UserPreview:

- UserID
- Login
- Rights
- Name
- Surname

### UserUpdate:

То же что и User только все поля необязательные.
